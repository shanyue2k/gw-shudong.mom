隐私政策 (Privacy Policy)

保护您的个人隐私与数据安全，是 GW 树洞立足的根本基石

核心隐私承诺：绝对零日志政策 (Strict No-Logs Policy)

GW 树洞郑重声明并在此承诺：我们绝不记录、收集、存储或向任何第三方分享用户在连接加速服务期间的任何使用日志与上网足迹！

网络自由与隐私保护是不可侵犯的基本权利。我们通过系统底层架构设计，使得我们的加速服务器在物理与逻辑层面上均不具备记录用户活动数据的能力。

我们绝不收集和记录的信息清单

  • 浏览历史与目标网址：我们绝不记录您访问的任何网站、域名、页面或 API 请求。
  • DNS 解析查询：所有的 DNS 解析请求均在 RAM 内存中完成即时处理，不留存任何日志。
  • 传输数据与通信内容：用户传输的任何数据均通过强加密传输通道，我们绝不解密、窥探或篡改用户数据包。
  • 用户原始源 IP 地址：我们不记录您本地网络的公网 IP 地址或物理地理定位。
  • 连接时间戳关联：我们不会将用户的具体连接/断开时间戳与您的真实身份进行绑定留存。

技术实现与无盘运行机制 (RAM-Only Servers)

为了从根本上消除数据泄露的风险，GW 树洞所有核心节点全面升级为纯内存无盘运行（RAM-Only）架构：

  • 无硬盘持久化存储：服务器操作系统及应用均仅在随机存取存储器（RAM）中运行，物理硬盘不写入任何会话数据。
  • 重启即物理销毁：一旦服务器重启或发生电力中断，RAM 中的全部运行数据立即被永久抹除，物理上不可能发生数据提取。
  • 端到端高强度加密：连接全程采用 ChaCha20 / AES-256-GCM 等高级加密算法，防御传输层面的嗅探与篡改。

维持服务运行所需的最小化数据

为确保计费系统与套餐配额正常运作，我们仅收集并保留以下最低限度的运营账户数据：

  • 账户标识信息：注册时提供的邮箱地址及经由单向不可逆哈希（Bcrypt/Argon2）加密的密码。
  • 总流量使用统计：仅统计您在计费周期内已消耗的总流量数值（如已用 45GB/100GB），不包含流量去向与内容。
  • 支付凭证参考：支付网关返回的订单交易号与到期时间，用于为您激活套餐权限（我们不保存您的银行卡号或敏感支付密码）。
